# 攝氏轉華氏
## 題目敘述
氣象站要把測到的攝氏溫度換算成華氏溫度給國外的資料庫使用，換算公式是：  
`F = C × 9 ÷ 5 + 32`  
請讀入攝氏溫度 C，計算並輸出對應的華氏溫度 `F`。  

## 輸入格式
輸入一行，一個實數 `C`，代表攝氏溫度。  

## 輸出格式  
輸出一行，即換算後的華氏溫度 `F`。用 `double` 存、算完直接印出即可，不需要額外設定小數位數。  

## 限制
> −100 ≤ `C` ≤ 100  
> `C` 最多到小數點後 1 位  

## 範例一
範例輸入：  
```
0
```
範例輸出：  
```
32
```
## 範例二
範例輸入：  
```
37
```
範例輸出：
```
98.6
```
人體體溫大約是攝氏 37 度，換算成華氏就是我們常聽到的 98.6 度。
